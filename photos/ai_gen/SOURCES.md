# photos/ai_gen: AI-generated test photos

**Every image in this folder is an AI-generated test photo (made by an image model), not a real capture.** None of
them shows the owner's desk or any real place. They were generated by the project owner with a text-to-image model
to try Rehearsal on more than one photo-like table. The model's own perspective is not guaranteed to be physically
consistent, which is part of what the calibration checks below test.

| file | what it is |
|---|---|
| `desk_lamp_mug.png` | generated, 1448x1086: oak desk, mug, cork coaster, black lamp, laptop, paperback, phone, cactus |
| `desk_walnut.png` | generated, 1448x1086: walnut desk, mug, cork coaster, closed tablet, book, phone, scissors, succulent, lamp |
| `desk_ruler.png` | generated, 1448x1086: desk with arm lamp, mug, stacked books, notebook, mouse, tray, steel ruler, cable |
| `desk_oak_laptop.png` | generated, 1448x1086: mug, laptop, glasses, earbuds case, notebook, pen cup, lamp (not used yet) |
| `collage_src.png` | generated 5-tile collage, 1448x1086 |
| `tile_desk.png`, `tile_kitchen.png`, `tile_coffee.png`, `tile_windowsill.png`, `tile_bedside.png` | crops of `collage_src.png` along its white gutters (boxes in `docs/aigen_photos.md`), not resized |

Derived files (`aigen_*.overlay.png`, `aigen_*.twin_compare.png`, `*.twin_overlay.png`, `*.twin_render.png`,
`*.fidelity.json`) come from `scripts/aigen_photo_scene.py` and `scripts/fidelity_eval.py`. Because these images are
synthetic, Meta API calls on them use Contributor mode (`data="public"`). Results: `docs/aigen_photos.md`.
