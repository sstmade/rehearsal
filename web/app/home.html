How it works

From a photo to a plan
you can trust.

01 · PHOTO

Show it the table.

Any photo of a tabletop: the kitchen counter, a desk, a workbench. No scanning rig, no markers.

02 · PERCEIVE

Every object, named and outlined.

Muse Spark names what is on the table. SAM 3.1 traces an exact mask for each one. The camera and the tabletop are calibrated from the same photo.

Muse Spark · SAM 3.1
03 · TWIN

A physics twin, then a refined one.

Each object becomes a rigid body with mass and friction. That is what physics simulates. The photo is projected back onto it, and SAM 3D can rebuild any object as a full mesh.

MuJoCo · SAM 3D
04 · INSTRUCT

Say it in plain words.

Muse Spark compiles the instruction into checkable goals. When something is ambiguous, it asks. When it is unsafe, it refuses.

Muse Spark
05 · REHEARSE

Try the futures. Send only the verified one.

A search planner proposes carries and detours; physics runs every one. A plan is sent only if every goal holds and nothing else was disturbed.

Search + MuJoCo · no model calls

Built on Meta AI

Three models.
One honest verdict.

MUSE SPARK

Understands.

Reads the scene and the instruction, and turns them into goals that physics can check.

  • Names every object and the tabletop
  • Compiles words into goals
  • Asks when it's ambiguous, refuses when it's unsafe
SAM 3.1

Sees.

Pixel-exact masks for every object, which fit the object footprints and decide which photo pixels belong to whom.

  • Concept prompts per object class
  • Masks → primitive fits
  • Masks → texture ownership in the twin
SAM 3D

Refines.

Rebuilds any object from the single photo as a full 3D mesh, for a twin that looks like the real table.

  • Single-image object reconstruction
  • Swapped in for looks only
  • Physics stays on the primitives
