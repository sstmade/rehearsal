01Intent

Physics can certify the wrong goal.

A simulator checks whether the goal holds. It can’t tell whether it’s the goal you meant. That part belongs to the language model, so we measured it.

Make some room on the desk.

The model moved the mug to the coaster, then stacked the book on the laptop.

Physics: successYou: a book and a phone on your laptop

Put the cup in the fridge.

There is no fridge. The plan had no way to say no, so “nothing moved” passed.

Physics: successYou: it should have said so

So Rehearsal shows what it assumed, and asks when it should.

Before anything runs, the model lists its assumptions for you to confirm. It may ask one question, or refuse with a reason, instead of guessing.

Before rehearsing

“Which book should I put in the bowl: the large hardcover, medium paperback, or small notebook?”

or, for an impossible request

“The robot can only suction-pick and transport and has no cutting tool.”

03Reality

Then we checked the physics against a real robot.

Six recorded episodes of a real Franka arm from the public DROID dataset. Rehearsal rebuilt each table from the first camera frame, replayed the recorded motion, and predicted what would happen. Then we compared it with what the camera filmed.

Real robotRehearsal

5/6real outcomes predicted correctly
0false successes: it never said “this works” when the real arm failed
2.5 cmmedian error in where each object ended up, over 14 objects

!The honest miss

The real cup came up wedged on the closed fingers.

The gripper went inside the tapered cup and lifted it by wedging. Our gripper model has no wedge contact, and the twin’s cup was a plain cylinder, so in the replay the fingers landed on the rim and the cup fell off. Rehearsal said failure; the real arm succeeded. A false alarm, not a false success, and a cause we can name.

Replay mode: the robot’s motion is given, so this tests the twin (perception, geometry, contact, gripper), not the planner. The predictor never reads DROID’s success label. Source: docs/real_robot.md. Robot footage: DROID (Khazatsky et al., RSS 2024), CC BY 4.0.

          A closer look at one object

          Which single object is worth a second photo? Rehearsal tries re-measuring each one and reports the one that helps most. (Modelled as a sharper position estimate; a real second photo is future work.)

          Technical details value of re-observing each object, selection vs held-out runs

          Extra successes if only this object is re-observed

          A second look is modelled as a smaller position uncertainty (σ 1.2 cm → 0.4 cm) for that object. The object is chosen on one set of random runs (“selection”) and the gain is then measured on a fresh set (“held-out”), so the headline number isn't flattered by the choice.

          06

          Checked, estimated, assumed

          Every claim on this page is labelled by how it was earned.

          Checked by physics

          • Can the arm reach each object from above?
          • What touched what, and when
          • Did the goals hold at the end: on, inside, stacked, upright, still, nothing else disturbed

          Estimated

          • Friction and weight, varied by ±40 % and ±30 %
          • Where each object really is, within about a centimetre
          • The success rate, from 40 nudged runs

          Assumed, not checked

          • Grasping: a suction cup that holds whenever it lands on the top face
          • Objects are simple shapes (boxes, cylinders, bowls) for physics
          • Simulation only. No real robot was moved.
